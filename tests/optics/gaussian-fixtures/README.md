# Gaussian coefficient characterization

These are Film-Juicer native characterizations, not external-reference pixel
fixtures. Each logical preset retains its own immutable payload and context.
The cohort includes 28 literal cases and actual four-route scanner, visual-grain
and FIR-DIR descriptor products at 2, 6 and 12 micrometers per pixel: 188 arrays,
22,895 final f32 words. Empty native-helper cases characterize inactive inputs;
the active Rust API rejects radius zero/nonpositive sigma.

Each context records the unchanged whole native producer, retained executable,
capture and source/compiler/link evidence identities. Initial 136-array captures
and all four initial executables remain separately preserved. The larger pixel
scale supplements a discovered missing FIR consumer before fixture adoption;
it does not replace a numerical failure. Exact comparison passed in all four
matching native Debug/Release contexts using ordinary safe Rust f64 exp.

Every final f32 array agrees across contexts. Two positive-capture grain rows
have distinct selected Linux/Windows f64 exp primitive words; they remain in the
separate context payloads. No primitive tolerance, new evaluator, mirrored
half-kernel or normalization repair is used. Arithmetic promotes sigma first,
sums ascending unrounded exp results while storing first-rounded f32 samples,
then normalizes those samples in f64 and rounds to f32 again.

C++, Rust and the final C11 production probe read complete arrays and exact
radius/count/sigma bits. GPU consumers download real cache storage. Raw/facade
faults remain testing-ON only. Ordinary tests never write this directory.
