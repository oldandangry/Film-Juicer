# Reflected spatial-DIR boundary fixtures

These are Film-Juicer characterizations of the native reflected-YVV boundary
producer, not spektrafilm pixel references. Ordinary tests never regenerate them.
The manifest records four native Debug/Release contexts, source/compiler/link
inputs and retained original executables. Each context has 114 whole products
and 56 double-double primitive observations. Inputs are literal coefficient and
policy bits; accepted Slice 4 frame products supply the production coefficients.

Each preset-named JSON payload records key bytes, key, success or diagnostic, both retained axis
lengths, every row-major binary64 weight and both nine-word terminal arrays.
Combined storage is the three horizontal rows followed by the three vertical
rows. Active terminal matrices use their own terminal-size stride; remaining
members are positive zero. All comparisons are exact integer representations of
floating-point bits. The primitive observations preserve both double-double words,
including the explicit fused product residual. No numerical tolerance is widened.

`checked.json` supplies separately authored representation-safety and typed failure
expectations. `manifest.json` also specifies 171 production C11 result rows:
117 value/safety cases, 51 raw-admission/diagnostic cases and three lifetime cases.
Diagnostic lengths count bytes written without the NUL. These rows bind complete
values and metadata to the actual testing-OFF archive probe; they are not new
numerical captures. The original scientific inputs and payload hashes remain
distinct from this protocol schema.

The original 99-case cohort and later geometry extension were both executed by
the retained unchanged producers. Earlier capture inputs and results remain in
their validation campaigns. Changes to these expectations require a separate
review of provenance and candidate output under `out/validation/`.
