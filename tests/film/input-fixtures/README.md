# Native film-input compound characterization

These are Film-Juicer characterizations of the native compound producer at
`00d75a4d8c4d727e1c4e7961f557994c581cc3b0` (tree
`269b0cfa49188364c05051d142cbabf6412c59a2`), using its already accepted safe
mathematical leaves. They are independent of the new safe compound constructor
and are not external-reference pixel fixtures.

All four native Debug/Release configurations were captured before translation.
The manifest maps them to two byte-preserved payloads and records SHA-256 values.
Linux Debug/Release agree exactly; Windows Debug/Release agree exactly. Logical
captures remain distinct in provenance. The original 96-case captures and the
subsequent 140-case captures, source, compiler/link commands and failed capture
setup attempts remain in the implementation campaign evidence. Tests read these
files without generation or mutation.

The first 96 rows are one negative and one positive profile, both route
selections, four input spaces, three reconstruction methods and decoding on/off.
The remaining 44 rows use their `control` index to vary window/surface,
compression, metering, EV/mm and active/inactive filters. EV/mm use authored
`1.234567890123` / `36.123456789012` before their existing f32 narrowing; the
alternate EV is negative zero. UV is
`[0.314159265358979, 413.123456789012, 9.123456789012]`, IR is
`[0.271828182845904, 679.123456789012, 17.123456789012]`. Amount controls alternate
with index parity; meter is index modulo seven. The capture/test source binds
the remaining deterministic selectors.

Floating values are exact u32 words. Matrices are row-major; whites are XYZ;
sensitivity is wavelength-major `[81][3]` R/G/B, and surface coefficients are
`[3][15]` R/G/B. Identities are exact u64 values. No padding is recorded or
compared. All matrices, resolved controls, arrays, labels, sensitivity/scale,
source/hull/TC/family identities and complete native product/snapshot identities
are checked. A corrupted matrix-word control must be rejected.

The accepted inverse-A complete-product assignment and earlier inverse-B
explicit-input characterization remain unchanged. Existing leaf fixtures and
numerical bounds are not regenerated by this family. Reference maintenance must
capture a separately reviewed candidate under `out/validation/`; passing tests
never authorize changing these expectations.
