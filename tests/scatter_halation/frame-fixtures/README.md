# Scatter/halation frame fixtures

This is a Film-Juicer native characterization captured before replacing the
complete public C++ frame builder. `manifest.json` retains the producer revision,
source/body identity, original capture/executable hashes and native contexts.
The four logical native profiles share an exact physical payload; context and
LF/CRLF reconstruction retain each original byte-stream identity.

`inputs.json` declares fifty-two literal records and four active product pixel
words. `native-payload.json` records those fifty-two results, twenty completed
direct/print polarity products, and twelve sampled f64 exponential primitives.
Each successful result includes all twenty-one Gaussian records, every one of
nineteen FIR slots and four YVV fields, kinds/radii, strengths, amount and carried
recipe hash. Numbers representing floats are IEEE bit words in semantic RGB
order. Failures retain optional absence and full native diagnostics.

`checked.json` independently defines the fixed ABI envelopes and typed failure
locations/sigma. Finite computed sigma bits are exact; NaN payload bits are not a
contract. The manifest's eighty-six production outcomes combine the seventy-two
characterization rows with fourteen raw pointer/tag/diagnostic cases. Its raw
contracts do not acquire mathematical authority from replacement captures.

Ordinary tests never regenerate these files. Future candidates belong under
`out/validation/<preset>/` and require a separate provenance/behavior review. The
neighboring `fixtures/` external-reference payload, revision and numerical bounds
remain a separate authority. These fixtures establish neither GPU lifetime nor
installed-host visual acceptance.
