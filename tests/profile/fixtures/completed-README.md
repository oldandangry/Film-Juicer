# Completed profile fixtures

`completed.json` supplies exact expectations for the complete immutable safe-core
profiles. Ordinary tests use this file, the original frozen density fixtures and
shipped resources. They do not run the private capture tooling or read its paths.
No old density sample, identity, manifest, resource or historical evidence changes.

`completed-manifest.json` records source/capture hashes, the unchanged native
owners, pinned reference and producing command. Expectations were frozen before
the Rust completion token/digest encoder was implemented. Archival paths identify
provenance, not test inputs.

For all 28 profiles, source f32 array bits, adaptation presence and film digests
come from the unchanged `ProfileAssets.cpp` owners at `594c78b`. Linear sensitivity
is copied from the independently qualified 29 September Linux/Windows native
captures. Tests select the matching platform: the established five platform
powf differences remain intact. No sensitivity exception or tolerance is added.
The f64 source axis/model and density totals/layers remain governed by the
original `density.json` and `density-samples.bin` exact expectations.

The completed asset tokens are copied from the four existing independent native
replays over approved Rust density bits. All four replay tokens agree. These are
actual-bit identities under the permanent 30 September density exception; they
are distinct from old native density-derived asset tokens.

Forty small synthetic cases freeze metadata mapping, field/tag order, f32
value/NaN-mask encoding, optional adaptation flags/arrays, evaluator version,
retained source-f64/model bits and film digest decisions. The unchanged native
identity and digest functions supply the expectations. The cases use exact
Gaussian half responses and endpoints. Narrowing-infinity endpoints are supplied
analytically to the native token owner because native scalar exposure admission
has not yet migrated; the native sampler is not claimed to accept those inputs.
These cases are a product identity contract plus native characterization of the
unchanged digest and non-density fields, with exact bits and no epsilon.

Arrays of integers represent flattened IEEE-754 f32 bits. The synthetic `base`
and JSON-pointer `changes` are authored input documents. `totals` are
exposure-major CMY bits. Model matrices remain channel-major; the original binary
fixture supplies layer-major density expectations. The final zero rule is 0 → 1
only at the completed asset-token boundary; nonzero hashes are unchanged.

The safe core additionally checks singleton/duplicate axes, descending f64 that
narrows to f32 equality, actual descending f32 rejection, ordered infinities,
unusual models, optional/null data, computed failures, controlled reservation
failure, retained f64 and signed-zero identity distinctions, and equivalent JSON
serialization. Shifted wavelength labels remain stored and hashed without
resampling or changing positional sample meaning. Spectral preparation and
production publication remain later migration responsibilities.
