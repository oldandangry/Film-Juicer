# Print balance native characterization

The manifest selects independent Linux/Windows Debug/Release captures of the
unchanged actual native producer, after unchanged-body extraction and existing
real-product word/hash checks. The 42 literal inputs retain exact f32 words;
120 actual product rows retain both polarities, direct omission, three spectral
reconstruction selections and exposure/gamma/light/preflash/output dependencies.
Successful balances contain nine f32 words and two u64 hashes. C/M/Y densities
and RGB print sensitivity/exposure components keep authored positional order.

New typed ABI failure metadata is normative and separate from native bool/text
observations. The seven balance hash lanes, signed-zero content hashing, scalar
bit widening, narrowing points and failure priority are exact contracts. There
is no new numerical exception or tolerance. Existing fixtures and illuminant
erff supplements are unchanged. Ordinary tests read these captures; they never
regenerate them. The temporary native capture entry is removed after caller
replacement evidence; its source/provenance is retained in implementation evidence.
