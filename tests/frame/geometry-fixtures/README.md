# Frame geometry characterization

These immutable Film-Juicer characterizations cover 15 endpoint conversions and
22 scalar geometry constructions. They are native migration expectations, with
exact signed fields, final f32 pixel words and the f64 widening consumed by
diffusion. They do not establish positive dimensions or image allocation coverage.

The unchanged mathematical fragments in `JuicerEffect::render` were factored into
shared native bodies at source HEAD `66eb51a2613bbc08c026f592a0055206ada93517`.
Both real callback sites used those bodies before replacement. The isolated
adapter target captured them before owner creation, bootstrap or CUDA admission.
Each logical preset retains its own source/compiler/FP context and retained
producer executable identity. All four payloads agree exactly. Context records
are provenance; ordinary tests need no retained executable or private workbench.
The temporary native capture bodies and maintenance dispatch are removed after
replacement readers and real callback gates pass.

`inputs.json` specifies the finite cohort. The manifest separately declares the
checked product boundary expectations and 69 final C11 production probe rows.
NONE, RAW, DOMAIN_RANGE and PANIC are closed failure reasons; DOMAIN_RANGE belongs
only to endpoint conversion. Raw admission, cleared outputs and diagnostics are
product contracts rather than outputs retrospectively attributed to the native
mathematical producer. Panic injection exists only with test support.

Rust core, the compiled C11 caller, checked production/facade entries, native
wrapper and final testing-OFF C11 probe consume these frozen fields and words.
The actual callback fixture additionally exercises current image metadata,
conditional phases, live time-bearing canonical queries, routes, early failure
priority and image leases. Ordinary tests never regenerate expectations.

The public JSON representation uses LF. Windows producer CRLF bytes remain in the
retained native captures; each context records that original line ending and
producer hash. The shared fixture check reconstructs and verifies those original
bytes. This encoding adoption changes no field, input, expected word or bound.

A null reported field in malformed-peer C11 results means its foreign output or
failure record was not addressable and was not read. It is not a wire reason or
an additional success/failure tag. Every valid writable peer is checked independently.
