# Film TC native expectations

The manifest records the accepted 5b134fb native parent, exact source/resource
identities and actual compiler/link commands for all four presets. Complete
captures and fresh-process repetitions preceded integration. Ordinary Rust
exp/exp2/sqrt/hypot/pow and complete private operations then matched exactly;
only native expectations supplied these new fixtures.

Each record contains 23 bounded leaf cases and 36 real route/polarity/method
products. Cases 0–8 supply all 147456 little-endian IEEE f32 words, including
positive-zero padding. Further cases retain failure diagnostics, sampling,
intermediates and full native byte digests without duplicating large tables.
The source is C/M/wavelength; result lanes are R/G/B/padding. Hanatos is
irradiance; Arctic is reflectance with per-channel neutral response. Host
exposure uses Mitchell; input compression uses bilinear remapping.

Native undefined floor/int cases are deliberately not executed as oracles.
Their categories require ordinary computed failure before index conversion.
Malformed raw extents are separate structural failures. Native method/key
preguards are distinct from the raw schema. Both zero signs/NaN direct-builder
blur bypasses are characterized separately from recipe control validation.

The manifest preserves every expanded preset record and all original bytes.
Shared records indicate proven equality, not looser bounds or a candidate
oracle. These are Film-Juicer characterization and exact migration contracts;
they are not new spektrafilm Python or CUDA algorithms. Reference maintenance
is an explicit operation; CTest never regenerates expectations.
