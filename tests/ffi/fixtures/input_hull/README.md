# Input compression hull fixtures

These are exact-bit product-contract captures of the approved native A8 producer
at `e9b4abbb8b146ffdd0f4fbc5f8c61e7e87134c2a`, before Rust translation.
All four native presets were captured and repeated in fresh processes. Exact
Rust primitive, complete intermediate, polygon/hash and A6 regression gates
passed before adoption. The manifest names each capture and its byte identity.
Files share a name only when the complete payload is byte-identical.

The records preserve 14 source/structure/failure cases, all f64 locus/center,
1024 ordered forward/weighted/inverse complex values, radii/scale, 1025 closed
f32 xy pairs, raw FNV identity, ray and exp contexts, and 18 actual caller
products. Only the native binding consumes wavelength-vector lengths; fixed
core inputs skip native shape cases 4–6. Values are raw IEEE u32/u64 words.
The primitive stream has four little-endian u64 words per deduplicated argument:
argument, cos result, sin result, and direction/forward/inverse context bits.
Each table offset selects a complete 147456-float TC RGBA payload, including
zero padding. Sources and polygon coordinates retain their authored order.

This is a native language-migration authority, not a newly regenerated upstream
baseline. Existing A6 fixtures and bounds are unchanged. Ordinary tests never
regenerate these files or read private capture material. Numerical disagreement
requires separate review; no tolerance or hash substitution is permitted.
